# Security Policy

## Supported Versions

Security updates are applied to the active development line:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The DockScope team takes security vulnerabilities seriously.

If you believe you have discovered a vulnerability in DockScope:

1. **Do not create a public GitHub issue.**
2. Email your findings and reproduction steps to: `security@dockscope.io`.
3. Provide details including:
   - Affected component(s)
   - Step-by-step reproduction instructions
   - Potential impact
   - Any suggested mitigations or patches

We will acknowledge receipt within 48 hours and work with you on coordinated disclosure.
